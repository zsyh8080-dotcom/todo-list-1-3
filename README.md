# todo-list-1-3

این پروژه را برای تمرین مباحث پایه JavaScript در تسک ۱-۳ نوشتم. یک لیست کار ساده است که می‌توان در آن کار جدید اضافه کرد، عنوان کارها را تغییر داد، آن‌ها را حذف کرد و وضعیت انجام شدنشان را عوض کرد.

در این مرحله خروجی برنامه فقط در Console نمایش داده می‌شود و هنوز مدیریت لیست با DOM پیاده‌سازی نشده است.

## اجرای پروژه

فایل `index.html` را در مرورگر باز کنید. سپس با کلید `F12` یا از بخش ابزارهای توسعه‌دهنده، تب **Console** را باز کنید تا خروجی نمونه‌ها را ببینید. در VS Code هم می‌توانید از Live Server استفاده کنید؛ نصب آن برای اجرای پروژه ضروری نیست.

پروژه به نصب پکیج یا ابزار ساخت نیاز ندارد.

## قابلیت‌ها

- اضافه کردن کار با `addTask(title)`
- حذف کار با `removeTask(id)`
- ویرایش عنوان با `editTask(id, newTitle)`
- تغییر وضعیت انجام شدن با `toggleTask(id)`
- نمایش همه کارها با `showTasks()`
- نمایش کارهای انجام‌شده با `showCompletedTasks()`
- نمایش کارهای باقی‌مانده با `showPendingTasks()`
- نمایش تعداد کل، انجام‌شده و باقی‌مانده با `showTaskSummary()`

## یک نمونه استفاده

بعد از باز شدن صفحه، می‌توانید این دستورها را در Console اجرا کنید:

```js
addTask("تمرین توابع");
showTasks();
showTaskSummary();
```

برای حذف یا ویرایش یک کار، از شناسه‌ای استفاده کنید که در خروجی `showTasks()` نشان داده می‌شود.

## فایل‌ها

- `index.html`: صفحه ساده و اتصال فایل JavaScript
- `script.js`: منطق لیست کارها و نمونه اجرای توابع

کارها در یک آرایه در حافظه نگهداری می‌شوند و با بارگذاری دوباره صفحه، تغییرات از بین می‌روند و نمونه‌های اولیه دوباره اجرا می‌شوند.
